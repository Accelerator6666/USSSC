# USSSC v0.4 — Local Dashboard & Settlement Reminders

## Scope

v0.4 is intentionally implemented before v0.2/v0.3 so the browser extension becomes useful as a daily local settlement tracker without requiring brokerage credentials or a cloud backend.

Included:

- local trade records
- expected settlement state
- upcoming settlement dashboard
- one-time settlement-day notifications
- local reminder-time settings
- Chrome / Edge Manifest V3 service worker

Not included yet:

- broker-confirmed settlement state
- settled/unsettled cash ledger
- Good Faith Violation detection
- IBKR import
- cloud synchronization

## Local data model

Each record is stored in `chrome.storage.local`:

```ts
interface StoredTrade {
  id: string;
  createdAt: string;
  symbol: string;
  side: "buy" | "sell";
  quantity: number;
  price?: number;
  assetType: "equity" | "etf";
  tradeDate: string;
  settlementDate: string;
  cycle: `T+${number}`;
  ruleLabel: string;
  remindedForSettlementDate?: string;
}
```

The stored settlement date is the output of `@usssc/core` at record-creation time. This keeps the Dashboard deterministic and avoids silently changing a historical record if future rule data changes.

## Dashboard state

The extension compares the calculated settlement date with the device-local current calendar date:

```text
settlementDate > today   -> pending
settlementDate = today   -> settles today
settlementDate < today   -> estimated settled / date passed
```

This is a UI state only. It must not be interpreted as broker confirmation of completed settlement.

## Reminder lifecycle

The background service worker watches `chrome.storage.local` and rebuilds extension-owned settlement alarms whenever trades or settings change.

Alarm name:

```text
usssc:settlement:<trade-id>
```

Behavior:

1. reminders disabled -> no settlement alarms
2. past settlement date -> no alarm
3. previously notified for the same settlement date -> no alarm
4. future date -> alarm at configured local time
5. browser starts late on the settlement date -> reminder fires shortly after startup
6. alarm fires -> notification is displayed and the trade is marked as reminded

The service worker clears only alarms with the USSSC settlement prefix; it does not touch unrelated extension alarms.

## Privacy

No host permissions are required for v0.4.

The extension requests only:

```text
storage
alarms
notifications
```

Trade data stays in the browser's extension-local storage. There is no USSSC backend in this version.

## Future compatibility

The local record format is deliberately small. v0.2 can extend records with cash-lot or funding-dependency identifiers without changing the existing settlement engine. v0.3 broker adapters can import data into the same `StoredTrade` shape before adding broker-specific metadata.
